# WanderLust

WanderLust is a full-stack  web application where users can discover unique stays, create property listings, upload images, and share reviews.  
The project is built using Node.js, Express.js, MongoDB, and EJS, with a clean and responsive interface.

## Features
- User authentication and authorization.
- Create, edit, and delete property listings.
- Upload listing images.
- Add reviews and ratings.
- Search and filter listings.
- Responsive and user-friendly UI.

## Tech Stack
- Frontend: HTML, CSS, JavaScript, EJS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Image Storage: Cloudinary
- Authentication: Passport.js / Session-based login

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/WanderLust.git
   cd WanderLust
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file and add your environment variables:
   ```bash
   ATLASDB_URL=your_mongodb_url
   SECRET=your_secret_key
   CLOUD_NAME=your_cloud_name
   CLOUD_API_KEY=your_cloudinary_api_key
   CLOUD_API_SECRET=your_cloudinary_api_secret
   ```

4. Run the project:
   ```bash
   npm start
   ```

5. Open in browser:
   ```bash
   http://localhost:8080
   ```

## Purpose
This project was created to practice full-stack web development concepts, including backend APIs, database integration, authentication, and frontend design.
